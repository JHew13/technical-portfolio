# Technical Portfolio

Sanitized examples of Python, SQL, and PHP work I developed for internal business applications, automation, data analysis, and troubleshooting.

> **Sanitization note:** These samples are based on code I originally wrote. Proprietary company names, database objects, internal URLs, credentials, identifiers, business-specific values, and sample data have been removed or replaced with generic equivalents. Because the original systems are not public, some examples are intended to demonstrate code structure and problem-solving rather than run as standalone applications.

## Python

- **`active_directory_user_export.py`** — Retrieves directory user information and transforms it into structured data for reporting.
- **`ruleset_etl_columns.py`** — Extracts ruleset data, selects and transforms relevant fields, and prepares structured output.
- **`ruleset_etl_excel.py`** — Processes ruleset/source-file data and prepares it for structured storage and analysis.
- **`sentence_similarity_analysis.py`** — Compares workflow text to identify exact and partial similarities and potential duplicates.

## SQL

- **`linked_workflow_search.sql`** — Traces relationships between linked workflows while limiting results to the latest revision.
- **`workflow_by_review_type.sql`** — Analyzes workflow relationships by review type across multiple related tables.
- **`workflow_component_search.sql`** — Identifies workflows that use a selected UI component and traces related configuration.

## PHP

- **`audit_dates_agent_view.php`** — Retrieves audit-related database records for display in an internal web interface.
- **`fax_error_tracker.php`** — Database-backed web application for capturing, searching, and maintaining operational error records.
- **`supervisor_agent_dashboard.php`** — Internal supervisor dashboard for retrieving and presenting individual employee operational data.

## Technologies Demonstrated

Python, pandas, Selenium, SQL/T-SQL, PHP, MySQL, JavaScript/AJAX, HTML/CSS, Active Directory/LDAP, Excel automation, ETL-style data processing, relational database querying, data validation, and troubleshooting.
